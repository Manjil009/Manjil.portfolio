# Manjil Dangol Portfolio

## How to view this project

1. Open the project folder in VS Code.
2. Open `index.html` in a browser.
3. Explore the portfolio sections using the navigation menu.
4. Select **WORKS** in the navigation to open `works.html`.

### Recommended option

Install the **Live Server** extension in VS Code, then:

1. Right-click `index.html`.
2. Select **Open with Live Server**.
3. The portfolio will open in your browser.

## Adding more work

Open the **WORKS** page, complete the project form, choose an image, and select **ADD TO ARCHIVE**.

Uploaded projects are currently stored in the browser's local storage. This means they remain available in that browser on that device, but are not yet shared publicly with other visitors. Public uploads require connecting the form to a service such as Firebase, Supabase, or Cloudinary.

## Project files

- `index.html` - Main portfolio page
- `works.html` - Additional works archive and upload form
- `style.css` - Shared styling
- `op.js` - Main portfolio interactions and animations
- `works.js` - Works archive functionality
